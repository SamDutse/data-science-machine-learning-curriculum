# Phase 3: Scikit-learn: Building ML Models

**Days 21-30** (10 days)

The longest ZTM section (about 7h 47min). Learn the full Scikit-learn workflow: prepare data, choose models, fit, evaluate, tune, save.

**ZTM sections covered (as listed on the ZTM course page):** Scikit-learn: Creating Machine Learning Models; Supervised Learning: Classification + Regression
