**Days 1-10** (10 days)

Learn core Python with W3Schools while watching ZTM's Introduction, Machine Learning 101 and the Machine Learning & Data Science Framework sections.

**ZTM sections covered (as listed on the ZTM course page):** Introduction; Machine Learning 101; Machine Learning and Data Science Framework; The 2 Paths
