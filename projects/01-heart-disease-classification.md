# Project 1: Heart Disease Classification

**Days:** Days 31-38

Predict whether a patient has heart disease from health parameters.

## Requirements

- [ ] Problem definition, data, metric and features written down
- [ ] Exploratory data analysis with at least 4 charts
- [ ] Three baseline models compared
- [ ] Hyperparameter tuning with RandomizedSearchCV and GridSearchCV
- [ ] ROC curve, confusion matrix and classification report
- [ ] Feature importance and next steps
- [ ] README with limitations. State clearly that this is a learning model, not a medical tool.

## Presentation

Student presents in 5 minutes: problem, best model, the metric that matters most and one limitation.
