# Capstone Project

**Days:** Days 57-60

Choose your own problem and dataset (local or African data is encouraged) and deliver an end-to-end project.

## Requirements

- [ ] Clear problem statement and why it matters
- [ ] Dataset documented with source and licence
- [ ] Six-step framework applied and explained
- [ ] At least two models compared with a suitable metric
- [ ] Charts that tell the story to a non-technical audience
- [ ] README, requirements/environment file and clean notebook
- [ ] 5-7 minute presentation

## Presentation

Graded with the final capstone rubric.
