## Learning objectives

By the end of today the student can:

- Write a custom evaluation function
- Run quick experiments on a subset

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Functions](https://www.w3schools.com/python/python_functions.asp), [Math](https://www.w3schools.com/python/python_math.asp)

**ZTM video topics to watch (open in your offline copy)**

- Custom RMSLE evaluation function
- Scoring on training vs validation data
- Training on a subset for faster experiments

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Write RMSLE as a function, evaluate train and validation scores, and train on subsets to experiment quickly.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Report RMSLE for train and validation sets and explain what the difference means.

Save work as `exercises/day-44_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 44: <topic>`.
