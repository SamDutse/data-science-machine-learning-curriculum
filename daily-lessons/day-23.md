# Day 23: Scikit-learn III: choosing the right estimator

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 22](day-22.md) | [Roadmap](../ROADMAP.md) | [Next: Day 24](day-24.md)

## Learning objectives

By the end of today the student can:

- Pick a suitable estimator for a problem
- Explain what a Random Forest is

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Linear Regression](https://www.w3schools.com/python/python_ml_linear_regression.asp), [ML Decision Tree](https://www.w3schools.com/python/python_ml_decision_tree.asp)

**ZTM video topics to watch (open in your offline copy)**

- Scikit-learn's machine learning map
- Regression vs classification estimators
- Random Forests and the idea of ensembles

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Use the sklearn map to choose models for three problems. Compare linear, tree-based and ensemble models.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** For 5 problems, write which estimator you would try first and why.

Save work as `exercises/day-23_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 23: <topic>`.
