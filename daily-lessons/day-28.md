# Day 28: Scikit-learn VIII: improving a model

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 27](day-27.md) | [Roadmap](../ROADMAP.md) | [Next: Day 29](day-29.md)

## Learning objectives

By the end of today the student can:

- Tune a model with a search
- Compare tuned and default results

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Grid Search](https://www.w3schools.com/python/python_ml_grid_search.asp), [ML Scale](https://www.w3schools.com/python/python_ml_scale.asp)

**ZTM video topics to watch (open in your offline copy)**

- Hyperparameters
- Tuning by hand
- RandomizedSearchCV
- GridSearchCV
- Comparing tuned vs default models

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Tune a Random Forest manually, then with RandomizedSearchCV and GridSearchCV. Compare time and score.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Report default vs tuned score for one model, with the best hyperparameters found.

Save work as `exercises/day-28_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 28: <topic>`.
