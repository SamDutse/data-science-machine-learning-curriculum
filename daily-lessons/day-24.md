# Day 24: Scikit-learn IV: fit and predict

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 23](day-23.md) | [Roadmap](../ROADMAP.md) | [Next: Day 25](day-25.md)

## Learning objectives

By the end of today the student can:

- Fit a model and make predictions
- Interpret predicted classes and probabilities

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Logistic Regression](https://www.w3schools.com/python/python_ml_logistic_regression.asp), [ML KNN](https://www.w3schools.com/python/python_ml_knn.asp)

**ZTM video topics to watch (open in your offline copy)**

- fit(), predict() and predict_proba()
- Reading model outputs
- Comparing models on the same data

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Fit a Logistic Regression, KNN and Random Forest on the same data and compare their predictions.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a helper function that fits several models and returns their test scores.

Save work as `exercises/day-24_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 24: <topic>`.
