# Day 18: NumPy III: comparing, sorting and randomness

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 17](day-17.md) | [Roadmap](../ROADMAP.md) | [Next: Day 19](day-19.md)

## Learning objectives

By the end of today the student can:

- Filter arrays with conditions
- Use a random seed for reproducible results

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Array Filter](https://www.w3schools.com/python/numpy/numpy_array_filter.asp), [NumPy Random](https://www.w3schools.com/python/numpy/numpy_random.asp), [NumPy ufunc](https://www.w3schools.com/python/numpy/numpy_ufunc.asp)

**ZTM video topics to watch (open in your offline copy)**

- Comparison operators
- Sorting arrays
- Turning images into NumPy arrays
- Random numbers and reproducibility (seed)
- NumPy exercises

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Filter and sort arrays; set random seeds. Load an image as an array and inspect it. Work through ZTM's NumPy exercises.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Generate a random dataset with a seed and write 3 filters over it.

Save work as `exercises/day-18_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 18: <topic>`.
