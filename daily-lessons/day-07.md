# Day 07: Lists, tuples and features

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 06](day-06.md) | [Roadmap](../ROADMAP.md) | [Next: Day 08](day-08.md)

## Learning objectives

By the end of today the student can:

- Store and change data in lists and tuples
- Tell features from labels

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Lists](https://www.w3schools.com/python/python_lists.asp), [Tuples](https://www.w3schools.com/python/python_tuples.asp)

**ZTM video topics to watch (open in your offline copy)**

- Framework step 3: evaluation (accuracy, error, baselines)
- Framework step 4: features (numerical, categorical, derived)

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Represent observations and features with lists and tuples. Pick features for a house-price prediction.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create a list of 10 observations and list the features that describe each.

Save work as `exercises/day-07_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 07: <topic>`.
