# Day 22: Scikit-learn II: converting and filling data

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 21](day-21.md) | [Roadmap](../ROADMAP.md) | [Next: Day 23](day-23.md)

## Learning objectives

By the end of today the student can:

- One-hot encode categories
- Fill missing values without data leakage

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Cleaning Empty Cells](https://www.w3schools.com/python/pandas/pandas_cleaning_empty_cells.asp), [ML Categorical Data](https://www.w3schools.com/python/python_ml_preprocessing.asp)

**ZTM video topics to watch (open in your offline copy)**

- Converting categorical data to numbers (one-hot encoding)
- Filling missing values (pandas and Scikit-learn imputers)
- Why scaling can matter

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Encode categorical columns and impute missing values on a messy dataset. Discuss why you fit transformers on training data only.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Prepare a messy dataset so that every column is numeric and has no missing values.

Save work as `exercises/day-22_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 22: <topic>`.
