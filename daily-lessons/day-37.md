# Day 37: Project 1: feature importance and experimentation

**Phase 4:** Milestone Project 1: Heart Disease Classification (Days 31-38)

[Previous: Day 36](day-36.md) | [Roadmap](../ROADMAP.md) | [Next: Day 38](day-38.md)

## Learning objectives

By the end of today the student can:

- Extract and plot feature importance
- Plan the next experiments

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Matplotlib Bars](https://www.w3schools.com/python/matplotlib_bars.asp), [Dictionaries](https://www.w3schools.com/python/python_dictionaries.asp)

**ZTM video topics to watch (open in your offline copy)**

- Model coefficients
- Feature importance
- Experiment ideas: more data, other models, further tuning

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Plot coefficients/feature importances and discuss what the model relies on. List experiments to try next.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create a feature importance chart and a list of 3 next experiments.

Save work as `exercises/day-37_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 37: <topic>`.
