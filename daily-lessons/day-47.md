# Day 47: Data engineering: where data comes from

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 46](day-46.md) | [Roadmap](../ROADMAP.md) | [Next: Day 48](day-48.md)

## Learning objectives

By the end of today the student can:

- Describe how data moves from source to data scientist
- Name the role of each big data tool

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[JSON](https://www.w3schools.com/python/python_json.asp), [File Handling](https://www.w3schools.com/python/python_file_handling.asp)

**ZTM video topics to watch (open in your offline copy)**

- What data engineering is
- Data sources and databases
- Data lakes and warehouses
- Hadoop, Spark, Kafka and Flink: what they are used for

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Diagram a data pipeline for a Nigerian scenario (e.g., mobile money transactions or farm sensor readings). Read JSON and CSV data in Python.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Draw and explain a data pipeline for a problem in your community.

Save work as `exercises/day-47_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 47: <topic>`.
