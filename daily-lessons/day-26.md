# Day 26: Scikit-learn VI: classification metrics

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 25](day-25.md) | [Roadmap](../ROADMAP.md) | [Next: Day 27](day-27.md)

## Learning objectives

By the end of today the student can:

- Read a confusion matrix
- Choose between accuracy, precision and recall

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Confusion Matrix](https://www.w3schools.com/python/python_ml_confusion_matrix.asp), [ML AUC - ROC Curve](https://www.w3schools.com/python/python_ml_auc_roc.asp)

**ZTM video topics to watch (open in your offline copy)**

- Accuracy
- ROC curve and AUC
- Confusion matrix
- Classification report: precision, recall and F1

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Compute every classification metric on one model. Discuss costs of false positives vs false negatives (e.g., disease screening).

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Explain in plain English what precision and recall mean for a malaria test.

Save work as `exercises/day-26_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 26: <topic>`.
