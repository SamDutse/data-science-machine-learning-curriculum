## Learning objectives

By the end of today the student can:

- Define a regression problem and its metric
- Explain why order in time matters

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Pandas Read CSV](https://www.w3schools.com/python/pandas/pandas_csv.asp), [Analyzing Data](https://www.w3schools.com/python/pandas/pandas_analyzing.asp)

**ZTM video topics to watch (open in your offline copy)**

- Time-series regression problem definition
- Data dictionary
- Evaluation metric (RMSLE)
- Train / validation / test split by date

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Define the problem, understand the data dictionary, and load the dataset. Discuss why random splits can leak the future.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write the problem definition and evaluation metric explanation in the notebook.

Save work as `exercises/day-39_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 39: <topic>`.
