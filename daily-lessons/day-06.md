# Day 06: Booleans, operators and the first steps of the ML framework

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 05](day-05.md) | [Roadmap](../ROADMAP.md) | [Next: Day 07](day-07.md)

## Learning objectives

By the end of today the student can:

- Use comparison and logical operators
- Write a clear ML problem definition

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Booleans](https://www.w3schools.com/python/python_booleans.asp), [Operators](https://www.w3schools.com/python/python_operators.asp)

**ZTM video topics to watch (open in your offline copy)**

- Introduction to the six-step ML framework
- Step 1: problem definition
- Step 2: what data do you have

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Practise operators with true/false questions about data. Write a problem definition for a local problem.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a problem definition (what are we predicting, from what data) for any Nigerian-context problem.

Save work as `exercises/day-06_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 06: <topic>`.
