# Day 21: Scikit-learn I: the workflow and getting data ready

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 20](day-20.md) | [Roadmap](../ROADMAP.md) | [Next: Day 22](day-22.md)

## Learning objectives

By the end of today the student can:

- Separate X and y
- Split data reproducibly

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Classes/Objects](https://www.w3schools.com/python/python_classes.asp), [ML Getting Started](https://www.w3schools.com/python/python_ml_getting_started.asp)

**ZTM video topics to watch (open in your offline copy)**

- Scikit-learn overview and the end-to-end workflow
- Getting data ready: features X and label y
- Splitting data into train and test sets

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Walk through the sklearn workflow on a small dataset. Note: sklearn models are Python objects, so revisit classes and methods.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Take any CSV, choose a target column, and create X_train, X_test, y_train, y_test.

Save work as `exercises/day-21_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 21: <topic>`.
