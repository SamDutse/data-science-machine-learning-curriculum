# Day 52: Project 3: preprocessing and input pipelines

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 51](day-51.md) | [Roadmap](../ROADMAP.md) | [Next: Day 53](day-53.md)

## Learning objectives

By the end of today the student can:

- Build a reproducible image input pipeline
- Avoid data leakage between splits

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Array Shape](https://www.w3schools.com/python/numpy/numpy_array_shape.asp), [Array Reshape](https://www.w3schools.com/python/numpy/numpy_array_reshape.asp)

**ZTM video topics to watch (open in your offline copy)**

- Resizing and normalising images
- Batches
- Train, validation and test splits
- tf.data pipelines

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Resize and normalise images, create batches and build train/validation pipelines.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Show one batch of images with their labels from your pipeline.

Save work as `exercises/day-52_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 52: <topic>`.
