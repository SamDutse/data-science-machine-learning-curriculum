# Day 19: Matplotlib I: plotting basics

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 18](day-18.md) | [Roadmap](../ROADMAP.md) | [Next: Day 20](day-20.md)

## Learning objectives

By the end of today the student can:

- Create line, scatter, bar and histogram plots
- Name the parts of a figure

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Matplotlib Intro](https://www.w3schools.com/python/matplotlib_intro.asp), [Matplotlib Pyplot](https://www.w3schools.com/python/matplotlib_pyplot.asp), [Matplotlib Plotting](https://www.w3schools.com/python/matplotlib_plotting.asp)

**ZTM video topics to watch (open in your offline copy)**

- Plotting introduction
- Two ways to plot: pyplot vs object-oriented
- Anatomy of a figure
- Line, scatter, bar and histogram basics

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Create four plot types from NumPy arrays. Label every part of one figure.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Plot the same small dataset as a line, a bar and a scatter plot; which tells the story best?

Save work as `exercises/day-19_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 19: <topic>`.
