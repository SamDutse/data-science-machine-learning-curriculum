# Day 12: Environment setup II: Jupyter notebooks

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 11](day-11.md) | [Roadmap](../ROADMAP.md) | [Next: Day 13](day-13.md)

## Learning objectives

By the end of today the student can:

- Run and organise a Jupyter notebook
- Read a file and handle errors

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[File Handling](https://www.w3schools.com/python/python_file_handling.asp), [Try...Except](https://www.w3schools.com/python/python_try_except.asp)

**ZTM video topics to watch (open in your offline copy)**

- Jupyter Notebook walkthrough: cells, kernels, shortcuts
- Sharing an environment (environment file)
- Google Colab as an alternative

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Create the first notebook, read a text file, handle a missing-file error, and export environment.yml. Open the same notebook in Colab.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create notebook day-12.ipynb with markdown notes and three code cells; push to GitHub.

Save work as `exercises/day-12_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 12: <topic>`.
