# Day 48: Neural networks and TensorFlow setup

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 47](day-47.md) | [Roadmap](../ROADMAP.md) | [Next: Day 49](day-49.md)

## Learning objectives

By the end of today the student can:

- Explain inputs, weights, activations and loss
- Enable a GPU in Colab and import TensorFlow

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Classes/Objects](https://www.w3schools.com/python/python_classes.asp), [Inheritance](https://www.w3schools.com/python/python_inheritance.asp)

**ZTM video topics to watch (open in your offline copy)**

- Deep learning vs classical ML
- Unstructured data
- What a neural network is: layers, weights, activations, loss
- TensorFlow and Keras overview
- Google Colab with GPU

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Set up Colab with a GPU and import TensorFlow. Use the TensorFlow Playground (or similar) to see how networks learn.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Explain in your own words how a neural network learns, using an analogy.

Save work as `exercises/day-48_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 48: <topic>`.
