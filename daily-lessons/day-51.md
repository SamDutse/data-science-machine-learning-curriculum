# Day 51: Project 3 (Dog Vision): data and exploration

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 50](day-50.md) | [Roadmap](../ROADMAP.md) | [Next: Day 52](day-52.md)

## Learning objectives

By the end of today the student can:

- Load and explore an image dataset
- Check class balance and image shapes

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[File Handling](https://www.w3schools.com/python/python_file_handling.asp), [PIP](https://www.w3schools.com/python/python_pip.asp)

**ZTM video topics to watch (open in your offline copy)**

- Project overview: classifying 100+ dog breeds
- Getting the image data
- Exploring images and label distribution
- Image sizes and colour channels

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Download or load the dog breed dataset in Colab. View sample images and the class distribution.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create a summary of the dataset: number of classes, images per class, image sizes.

Save work as `exercises/day-51_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 51: <topic>`.
