# Day 05: Strings and exploring ML in practice

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 04](day-04.md) | [Roadmap](../ROADMAP.md) | [Next: Day 06](day-06.md)

## Learning objectives

By the end of today the student can:

- Slice and format strings
- Describe the inputs and outputs of a recommender

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Strings](https://www.w3schools.com/python/python_strings.asp), [Slicing Strings](https://www.w3schools.com/python/python_strings_slicing.asp), [String Formatting](https://www.w3schools.com/python/python_string_formatting.asp)

**ZTM video topics to watch (open in your offline copy)**

- Hands-on ML playground / demo tools
- Exercise: how would a recommendation engine work?

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Build a formatted text report from variables. Discuss: what data would a recommender need?

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a program that prints a formatted student report card.

Save work as `exercises/day-05_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 05: <topic>`.
