# Day 02: Python syntax and what machine learning is

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 01](day-01.md) | [Roadmap](../ROADMAP.md) | [Next: Day 03](day-03.md)

## Learning objectives

By the end of today the student can:

- Write short, readable Python with comments
- Explain machine learning in your own words

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Syntax](https://www.w3schools.com/python/python_syntax.asp), [Comments](https://www.w3schools.com/python/python_comments.asp)

**ZTM video topics to watch (open in your offline copy)**

- What is machine learning; AI vs machine learning vs data science
- How ML differs from traditional programming

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Practise syntax rules and indentation. Class discussion: where do you meet ML every day (maps, WhatsApp suggestions, mobile money fraud alerts)?

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a one-paragraph definition of ML in your own words and add it as comments in a .py file.

Save work as `exercises/day-02_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 02: <topic>`.
