# Day 41: Project 2: feature engineering with dates

**Phase 5:** Milestone Project 2: Bulldozer Price Regression (Days 39-46)

[Previous: Day 40](day-40.md) | [Roadmap](../ROADMAP.md) | [Next: Day 42](day-42.md)

## Learning objectives

By the end of today the student can:

- Create date-based features
- Keep an untouched copy of the data

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Fixing Wrong Data](https://www.w3schools.com/python/pandas/pandas_cleaning_wrong_data.asp), [Strings](https://www.w3schools.com/python/python_strings.asp)

**ZTM video topics to watch (open in your offline copy)**

- Enriching features from the sale date: year, month, day, day of week
- Dropping the original date column
- Keeping a copy of the data

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Create year, month, day and day-of-week features from the date column and compare with the original.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Add at least 4 new date features and show a sample of the result.

Save work as `exercises/day-41_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 41: <topic>`.
