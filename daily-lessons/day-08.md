# Day 08: Dictionaries, sets and modelling concepts

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 07](day-07.md) | [Roadmap](../ROADMAP.md) | [Next: Day 09](day-09.md)

## Learning objectives

By the end of today the student can:

- Represent a data row as a dictionary
- Explain why we split data three ways

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Dictionaries](https://www.w3schools.com/python/python_dictionaries.asp), [Sets](https://www.w3schools.com/python/python_sets.asp)

**ZTM video topics to watch (open in your offline copy)**

- Framework step 5: modelling in three parts (choose, fit, compare)
- Splitting data: training, validation and test sets

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Model a dataset row with a dictionary and find unique categories with a set. Explain train/validation/test with an exam analogy.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a short note explaining the three data splits using an analogy of your own.

Save work as `exercises/day-08_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 08: <topic>`.
