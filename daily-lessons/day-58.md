# Day 58: Portfolio and Kaggle

**Phase 7:** Communication, Portfolio & Capstone (Days 57-60)

[Previous: Day 57](day-57.md) | [Roadmap](../ROADMAP.md) | [Next: Day 59](day-59.md)

## Learning objectives

By the end of today the student can:

- Create a Kaggle profile and explore a dataset
- Set up a clean portfolio repository

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Pandas Tutorial](https://www.w3schools.com/python/pandas/default.asp), [ML Getting Started](https://www.w3schools.com/python/python_ml_getting_started.asp)

**ZTM video topics to watch (open in your offline copy)**

- Using Kaggle and ML competitions
- Building a portfolio on GitHub
- README and documentation good practice
- What to learn next

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Tidy all project repos, write clear READMEs, and pick a dataset for the capstone.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Publish one project with a README and share the link with your tutor.

Save work as `exercises/day-58_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 58: <topic>`.
