# Day 16: NumPy I: arrays

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 15](day-15.md) | [Roadmap](../ROADMAP.md) | [Next: Day 17](day-17.md)

## Learning objectives

By the end of today the student can:

- Create arrays of different shapes
- Explain how NumPy differs from lists

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[NumPy Intro](https://www.w3schools.com/python/numpy/numpy_intro.asp), [Creating Arrays](https://www.w3schools.com/python/numpy/numpy_creating_arrays.asp), [NumPy Data Types](https://www.w3schools.com/python/numpy/numpy_data_types.asp)

**ZTM video topics to watch (open in your offline copy)**

- NumPy introduction: why NumPy
- ndarrays: creating arrays, shapes, ranks, data types
- Viewing arrays and matrices

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Create 1D, 2D and 3D arrays. Compare speed of NumPy vs a Python list.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create five arrays of different shapes and describe each one's shape and dtype.

Save work as `exercises/day-16_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 16: <topic>`.
