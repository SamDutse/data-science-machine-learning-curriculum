# Day 04: Data types, numbers and types of ML

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 03](day-03.md) | [Roadmap](../ROADMAP.md) | [Next: Day 05](day-05.md)

## Learning objectives

By the end of today the student can:

- Identify int, float, str and bool values
- Match a problem to a type of ML

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Data Types](https://www.w3schools.com/python/python_datatypes.asp), [Numbers](https://www.w3schools.com/python/python_numbers.asp), [Casting](https://www.w3schools.com/python/python_casting.asp)

**ZTM video topics to watch (open in your offline copy)**

- Types of machine learning: supervised, unsupervised, transfer learning, reinforcement learning
- Classification vs regression at a glance

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Sort 10 real problems into supervised, unsupervised or reinforcement learning. Practise converting between data types.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write 5 problems from your own community and label each with its ML type.

Save work as `exercises/day-04_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 04: <topic>`.
