# Day 42: Project 2: turning data into numbers

**Phase 5:** Milestone Project 2: Bulldozer Price Regression (Days 39-46)

[Previous: Day 41](day-41.md) | [Roadmap](../ROADMAP.md) | [Next: Day 43](day-43.md)

## Learning objectives

By the end of today the student can:

- Convert string columns to numeric codes
- Fill missing values while recording where they were missing

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Cleaning Empty Cells](https://www.w3schools.com/python/pandas/pandas_cleaning_empty_cells.asp), [Casting](https://www.w3schools.com/python/python_casting.asp)

**ZTM video topics to watch (open in your offline copy)**

- Converting strings to categories
- Pandas category codes
- Filling missing numeric values and adding indicator columns
- Filling missing categorical values

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Convert text columns to category codes and fill missing values, adding 'was missing' flags.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Confirm that the dataset is fully numeric and has no missing values.

Save work as `exercises/day-42_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 42: <topic>`.
