# Day 14: Pandas II: selecting and viewing data

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 13](day-13.md) | [Roadmap](../ROADMAP.md) | [Next: Day 15](day-15.md)

## Learning objectives

By the end of today the student can:

- Select rows and columns confidently
- Filter and group data

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Pandas Read CSV](https://www.w3schools.com/python/pandas/pandas_csv.asp), [Analyzing Data](https://www.w3schools.com/python/pandas/pandas_analyzing.asp)

**ZTM video topics to watch (open in your offline copy)**

- Selecting and viewing data: head, tail, loc, iloc
- Boolean filtering
- Grouping and crosstabs; plotting from pandas

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Practise loc vs iloc and filter data with conditions. Use groupby to summarise.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Answer 5 questions about your CSV using filters and groupby.

Save work as `exercises/day-14_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 14: <topic>`.
