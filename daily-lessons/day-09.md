# Day 09: Conditions, loops and tuning, overfitting, underfitting

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 08](day-08.md) | [Roadmap](../ROADMAP.md) | [Next: Day 10](day-10.md)

## Learning objectives

By the end of today the student can:

- Write if/else rules and for loops
- Explain overfitting and underfitting

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[If...Else](https://www.w3schools.com/python/python_conditions.asp), [For Loops](https://www.w3schools.com/python/python_for_loops.asp)

**ZTM video topics to watch (open in your offline copy)**

- Tuning a model
- Comparing models
- Overfitting and underfitting; step 6: experimentation

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Write simple rule-based 'models' with if/else and loops (e.g., classify scores into grades). Contrast a rule-based approach with a learned one.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a loop that classifies a list of scores into grades and counts each grade.

Save work as `exercises/day-09_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 09: <topic>`.
