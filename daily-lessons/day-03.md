# Day 03: Variables and data science ideas

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Previous: Day 02](day-02.md) | [Roadmap](../ROADMAP.md) | [Next: Day 04](day-04.md)

## Learning objectives

By the end of today the student can:

- Create and use variables
- Name three industries using ML and what they predict

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Variables](https://www.w3schools.com/python/python_variables.asp)

**ZTM video topics to watch (open in your offline copy)**

- AI, machine learning and data science: how they overlap
- Real-world applications by industry

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Store details about a small dataset (e.g., 5 students, their ages and scores) in variables and print a summary.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create variables describing a farm, clinic or shop of your choice and print a report.

Save work as `exercises/day-03_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 03: <topic>`.
