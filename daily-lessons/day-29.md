# Day 29: Scikit-learn IX: saving models and putting it together

**Phase 3:** Scikit-learn: Building ML Models (Days 21-30)

[Previous: Day 28](day-28.md) | [Roadmap](../ROADMAP.md) | [Next: Day 30](day-30.md)

## Learning objectives

By the end of today the student can:

- Save and reload a trained model
- Build a preprocessing + model pipeline

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[File Handling](https://www.w3schools.com/python/python_file_handling.asp), [Functions](https://www.w3schools.com/python/python_functions.asp)

**ZTM video topics to watch (open in your offline copy)**

- Saving and loading a model (pickle / joblib)
- Putting it all together with pipelines
- Column transformers

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Build a Pipeline that cleans, encodes and models; save it; load it in a fresh notebook and predict.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Wrap your best model in a pipeline, save it, and load it again to confirm identical predictions.

Save work as `exercises/day-29_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 29: <topic>`.
