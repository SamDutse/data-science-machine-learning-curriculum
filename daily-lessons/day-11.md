# Day 11: Environment setup I: Conda and packages

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 10](day-10.md) | [Roadmap](../ROADMAP.md) | [Next: Day 12](day-12.md)

## Learning objectives

By the end of today the student can:

- Create a Conda environment
- Install and import the core data science libraries

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Modules](https://www.w3schools.com/python/python_modules.asp), [PIP](https://www.w3schools.com/python/python_pip.asp)

**ZTM video topics to watch (open in your offline copy)**

- Why we need environments
- Conda and Miniconda
- Creating and activating environments; installing packages
- The data science tool stack

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Install Miniconda/Anaconda, create an environment (e.g., ds60) with pandas, numpy, matplotlib, scikit-learn and jupyter. Import each to test.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Document your setup steps in a SETUP.md in your repo.

Save work as `exercises/day-11_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 11: <topic>`.
