# Day 53: Project 3: transfer learning

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 52](day-52.md) | [Roadmap](../ROADMAP.md) | [Next: Day 54](day-54.md)

## Learning objectives

By the end of today the student can:

- Build a transfer-learning model
- Explain why it needs less data than training from scratch

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Classes/Objects](https://www.w3schools.com/python/python_classes.asp), [Functions](https://www.w3schools.com/python/python_functions.asp)

**ZTM video topics to watch (open in your offline copy)**

- What transfer learning is
- Pretrained models as feature extractors
- Adding your own output layer
- Softmax for many classes

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Load a pretrained model, freeze its layers, and add a classification head for the dog breeds.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write why transfer learning suits small datasets; list one risk.

Save work as `exercises/day-53_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 53: <topic>`.
