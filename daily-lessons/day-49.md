# Day 49: Tensors and shapes

**Phase 6:** Data Engineering, Deep Learning & Dog Vision (Days 47-56)

[Previous: Day 48](day-48.md) | [Roadmap](../ROADMAP.md) | [Next: Day 50](day-50.md)

## Learning objectives

By the end of today the student can:

- Create and reshape tensors
- Move between NumPy arrays and tensors

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Creating Arrays](https://www.w3schools.com/python/numpy/numpy_creating_arrays.asp), [Array Reshape](https://www.w3schools.com/python/numpy/numpy_array_reshape.asp)

**ZTM video topics to watch (open in your offline copy)**

- Tensors vs NumPy arrays
- Shapes, ranks and data types
- Running on GPU

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Create tensors, reshape them, and convert between NumPy and TensorFlow.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create 5 tensors of different shapes and describe each.

Save work as `exercises/day-49_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 49: <topic>`.
