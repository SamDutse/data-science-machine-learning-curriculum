## Learning objectives

By the end of today the student can:

- Tune a regression model with RandomizedSearchCV
- Compare tuned vs baseline

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Grid Search](https://www.w3schools.com/python/python_ml_grid_search.asp), [Lambda](https://www.w3schools.com/python/python_lambda.asp)

**ZTM video topics to watch (open in your offline copy)**

- RandomizedSearchCV with limited iterations
- Choosing hyperparameters for speed vs accuracy
- Retraining the best model on all the data

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Tune with RandomizedSearchCV under a time budget and compare against the baseline.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Create a table of baseline vs tuned RMSLE.

Save work as `exercises/day-45_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 45: <topic>`.
