## Learning objectives

By the end of today the student can:

- Parse and sort by date
- Plot a target variable over time

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Datetime](https://www.w3schools.com/python/python_datetime.asp), [Cleaning Wrong Format](https://www.w3schools.com/python/pandas/pandas_cleaning_wrong_format.asp)

**ZTM video topics to watch (open in your offline copy)**

- Parsing dates when importing data
- Sorting by date
- Visualising sale price over time
- Working on a sample for speed

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Import with parsed dates, sort chronologically, and plot sale price against time. Work on a sample while experimenting.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Produce two time-based charts and list what you notice.

Save work as `exercises/day-40_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 40: <topic>`.
