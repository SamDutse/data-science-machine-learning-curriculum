# Day 15: Pandas III: manipulating and cleaning data

**Phase 2:** Data Science Tools: Environment, Pandas, NumPy, Matplotlib (Days 11-20)

[Previous: Day 14](day-14.md) | [Roadmap](../ROADMAP.md) | [Next: Day 16](day-16.md)

## Learning objectives

By the end of today the student can:

- Clean missing and duplicated data
- Add a derived column

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Cleaning Data](https://www.w3schools.com/python/pandas/pandas_cleaning.asp), [Cleaning Empty Cells](https://www.w3schools.com/python/pandas/pandas_cleaning_empty_cells.asp), [Removing Duplicates](https://www.w3schools.com/python/pandas/pandas_cleaning_duplicates.asp)

**ZTM video topics to watch (open in your offline copy)**

- Manipulating data: apply, string methods
- Fixing missing values
- Adding and removing columns; shuffling data
- Pandas exercises

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Clean a messy dataset: fill or drop missing values, remove duplicates, create new columns. Work through ZTM's Pandas exercises.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Submit a cleaned version of your dataset with a short note on every change you made.

Save work as `exercises/day-15_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 15: <topic>`.
