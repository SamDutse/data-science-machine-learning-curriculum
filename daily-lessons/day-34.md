# Day 34: Project 1: baseline modelling

**Phase 4:** Milestone Project 1: Heart Disease Classification (Days 31-38)

[Previous: Day 33](day-33.md) | [Roadmap](../ROADMAP.md) | [Next: Day 35](day-35.md)

## Learning objectives

By the end of today the student can:

- Train and compare three baseline models
- Write a reusable fit-and-score function

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Logistic Regression](https://www.w3schools.com/python/python_ml_logistic_regression.asp), [ML KNN](https://www.w3schools.com/python/python_ml_knn.asp)

**ZTM video topics to watch (open in your offline copy)**

- Splitting the data
- Trying Logistic Regression, KNN and Random Forest
- A fit-and-score helper function
- Baseline comparison

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Split the data and train three models. Plot their scores in a bar chart.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Submit a notebook with a baseline comparison chart and a one-line decision on which to tune.

Save work as `exercises/day-34_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 34: <topic>`.
