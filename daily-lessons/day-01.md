# Day 01: Welcome, setup and your first program

**Phase 1:** Python Foundations & ML Concepts (Days 1-10)

[Roadmap](../ROADMAP.md) | [Next: Day 02](day-02.md)

## Learning objectives

By the end of today the student can:

- Run Python code and print output
- Explain what the 60-day programme covers

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[Python Intro](https://www.w3schools.com/python/python_intro.asp), [Get Started](https://www.w3schools.com/python/python_getstarted.asp)

**ZTM video topics to watch (open in your offline copy)**

- How the course and the 60 days work
- Course outline and what you will build
- How to ask for help; set a daily learning streak

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Install Python and a code editor (or use an online Python editor). Run the first program. Create the student GitHub repo and a PROGRESS file.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a 5-line program that prints a short introduction about yourself.

Save work as `exercises/day-01_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 01: <topic>`.

## Completion checklist

- [ ] Run Python code and print output
- [ ] Explain what the 60-day programme covers
- [ ] W3Schools topics studied and examples tried
- [ ] ZTM video topics watched
- [ ] Homework finished and pushed to GitHub
- [ ] Progress ticked in [PROGRESS.md](../PROGRESS.md)
