# Day 35: Project 1: tuning the models

**Phase 4:** Milestone Project 1: Heart Disease Classification (Days 31-38)

[Previous: Day 34](day-34.md) | [Roadmap](../ROADMAP.md) | [Next: Day 36](day-36.md)

## Learning objectives

By the end of today the student can:

- Tune a model using search CV
- Compare tuned vs baseline

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Grid Search](https://www.w3schools.com/python/python_ml_grid_search.asp), [Functions](https://www.w3schools.com/python/python_functions.asp)

**ZTM video topics to watch (open in your offline copy)**

- Tuning KNN by hand
- RandomizedSearchCV for Logistic Regression and Random Forest
- GridSearchCV
- Comparing tuned models

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Tune KNN by hand, then tune two models with RandomizedSearchCV and refine the best with GridSearchCV.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Record baseline vs tuned scores for the three models in a table.

Save work as `exercises/day-35_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 35: <topic>`.
