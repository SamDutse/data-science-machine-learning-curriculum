# Day 36: Project 1: evaluating the tuned model

**Phase 4:** Milestone Project 1: Heart Disease Classification (Days 31-38)

[Previous: Day 35](day-35.md) | [Roadmap](../ROADMAP.md) | [Next: Day 37](day-37.md)

## Learning objectives

By the end of today the student can:

- Evaluate with several classification metrics
- Interpret errors in context

## 1. Before class (30-60 min, independent)

**Python (W3Schools): click and study**

[ML Confusion Matrix](https://www.w3schools.com/python/python_ml_confusion_matrix.asp), [ML AUC - ROC Curve](https://www.w3schools.com/python/python_ml_auc_roc.asp)

**ZTM video topics to watch (open in your offline copy)**

- ROC curve and AUC
- Confusion matrix
- Classification report
- Cross-validated metrics

Write down at least two questions and try every example yourself.

## 2. In class (60-120 min, guided practice)

Compute ROC/AUC, confusion matrix, classification report and cross-validated metrics for the best model.

The tutor asks the student to explain each decision out loud before moving on.

## 3. After class (30-60 min, independent)

**Homework:** Write a short interpretation of the confusion matrix: which error is worse here and why?

Save work as `exercises/day-36_<topic>.ipynb` (or `.py`) in the student's own repo and commit it with a message like `Day 36: <topic>`.
